# Simple Zone

Simple Zone, from Aurora Glance (part of Toz Industries): a free local shopping app. Type what you need and it shows the nearest places that have it, whether they're open now, and how to get there.

The iPhone app is to be built here, looking the same as the Android app and the website.

## Brand

- `assets/sz-mark.svg`: the SZ mark as a vector (use this for the app icon)
- `assets/sz-mark.jpg`: the same mark as a picture
- Teal `#04A4A2` (the S), navy `#0A2551` (the Z)
